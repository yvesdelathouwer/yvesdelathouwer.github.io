# Yves De Lathouwer — Adit Ltd

Free engineering software by **Adit Ltd** (Israel) and research on **EN 1992-4** (design of fastenings in concrete).
All programs run in the browser, are free and need no registration; each produces a full calculation report.

- Website (English): https://eng.adit.org.il/
- Website (Hebrew): https://www.adit.org.il/
- All programs: https://eng.adit.org.il/all-the-software/ · https://www.adit.org.il/all-the-software/
- Site: https://yvesdelathouwer.github.io/
